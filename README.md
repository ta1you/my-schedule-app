# My Schedule アプリ

シンプルなスケジュール管理アプリです。

## 公開URL
https://ta1you.github.io/my-schedule-app/

## 主な機能
- 予定の追加・編集・削除
- カレンダー表示
- ローカル保存（LocalStorage）
- PWA対応

## 開発環境
- HTML
- CSS
- JavaScript
